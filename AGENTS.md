# Инструкции для работы с daevox

## Назначение проекта

`daevox` — локальный desktop-чат с AI-агентом, долговременной памятью и веб-поиском.
Основные части проекта:

- `packages/*` — TypeScript-пакеты и Electron/React UI;
- `external/memory` — Python-сервис долговременной памяти;
- `external/web_search` — Python-сервис веб-поиска;
- `./daevox` — основной launcher проекта.

## Общие правила

- Перед изменениями изучать существующий код и следовать его локальным паттернам.
- Делать минимальные изменения, относящиеся к задаче.
- Не менять публичные API, формат данных или поведение соседних компонентов без необходимости.
- Не добавлять зависимости, если задачу можно решить существующими средствами.
- Не трогать незакоммиченные изменения пользователя.
- Не выполнять commit, reset, push или другие операции Git с изменением истории без явной просьбы.
- Не хранить секреты, API-ключи и локальные настройки в Git.

## TypeScript и Node.js

- Использовать Node.js `22.12+` и npm.
- Соблюдать текущую структуру npm workspaces и TypeScript project references.
- Сохранять ESM-совместимость проекта (`"type": "module"`).
- Для изменений в storage учитывать миграции Prisma и совместимость с существующей SQLite-базой.
- Для UI не менять существующие компоненты и визуальные паттерны без необходимости.

## Python

- Для `external/memory` и `external/web_search` использовать `uv`.
- Следовать существующей конфигурации Ruff, mypy и pytest.
- Не добавлять отдельные виртуальные окружения или файлы зависимостей вручную, если это не требуется текущей конфигурацией проекта.

## Локальные данные и артефакты

- Не коммитить `.env`, базы SQLite, `.vault/`, индексы памяти, `node_modules/`, `dist/` и другие build-артефакты.
- Не удалять и не сбрасывать локальную историю, Vault или индекс памяти без явной просьбы.
- Не редактировать сгенерированные файлы вместо исходников; после изменения исходников запускать соответствующую сборку.

## Проверки

После изменений запускать релевантные проверки. Для изменений в TypeScript обычно использовать:

```bash
npm run build
npm test --workspaces --if-present
```

Для изменений в `external/memory`:

```bash
cd external/memory
uv run ruff check .
uv run mypy src
uv run pytest
```

Для изменений в `external/web_search`:

```bash
cd external/web_search
uv run ruff check src tests
uv run ruff format --check src tests
uv run mypy src
uv run pytest -q
```

В итоговом сообщении кратко указывать изменённые области и выполненные проверки. Если проверку нельзя запустить, указывать причину.
